\section*{Выводы}

По результатам анализа были сделаны следующие выводы:

\begin{itemize}
	\item в проекте возникают перегрузки для системного аналитика, художника-дизайнера и технического писателя в связи с необходимостью выполнения ими одновременно нескольких задач. Необходимо перераспределить нагрузку для данных работников;
	\item затраты на выполнение проекта составляют 47986 руб., что не превосходит бюджета проекта в 50000 руб.;
	\item трудозатраты проекта составляют 9323 ч;
	\item затраты на работу программистов составляют около 50\% при трудозатратах, составляющих около 30\% от всех трудозатрат проекта;
	\item наименьшие затраты в группах мультимедиа, документации и интернет, наибольшие~---~в группе программистов. Считая программистов одинаково квалифицированными, стоит рассмотреть варианты более эффективного распределения программистов по задачам, однако нужно обратить внимание, что все задачи в которых задействованы программисты лежат на критическом пути;
	\item наименьшие трудозатраты аналогично в группах анализа, дизайна, документации, мультимедиа, наибольшие в группах программистов и ввода данных;
	\item затраты на аренду сервера составляют 12\% всех завтрат проекта. Для сокращения времени использования сервера, необходимо сократить время наполнения базы объектов, для чего привлечь дополнительный ресурс в виде наборщиков данных.
\end{itemize}
